# Kyaw's portfolio

A responsive static landing page. No dependencies, build step, or secrets required.

## Local development

From this repository, run `python3 -m http.server 8000 --bind 0.0.0.0`.
Open port 8000 in your development environment. Stop the server with Ctrl+C.

Edit `index.html` for content and `styles.css` for appearance.

## Publish with GitHub Pages

1. Commit and push `index.html`, `styles.css`, and this README to `main` on GitHub.
2. In the GitHub repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/ (root)**, then click **Save**.
5. Wait for the Pages deployment to finish (check the **Actions** tab).
6. Open https://kyawkyawhtun-nyc.github.io/kyaw-portfolio/ .

GitHub Pages is available for public repositories on GitHub Free. Private repository hosting depends on your GitHub plan.

This is a publishable starter page, not a completed professional portfolio. Add your biography, real projects, and preferred contact details before using it as a full portfolio. Future updates go live when pushed to `main` after Pages is configured.
